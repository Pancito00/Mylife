# 🔒 Security Policy – MyLife

La seguridad de los usuarios y la protección de su información son aspectos importantes para el proyecto **MyLife**.

Este documento establece las versiones compatibles y el procedimiento para reportar posibles vulnerabilidades de seguridad.

## Supported Versions

Actualmente, MyLife se encuentra en desarrollo. Se dará prioridad a las correcciones de seguridad de la versión más reciente disponible.

| Version | Supported |
| ------- | --------- |
| Latest (`main`) | :white_check_mark: |
| Previous versions | :x: |

## Reporting a Vulnerability

Si encuentras una posible vulnerabilidad de seguridad en MyLife, te pedimos que la reportes de manera responsable.

Para comunicar un problema:

1. Accede a la pestaña **Security** del repositorio de GitHub.
2. Si está habilitada la opción *Private vulnerability reporting*, utiliza ese medio para enviar el reporte de forma privada.
3. Describe el problema encontrado y los pasos generales para identificarlo.
4. Espera la revisión por parte de los responsables del proyecto.

### ¿Qué sucede después del reporte?

- Se revisará la vulnerabilidad reportada.
- Se evaluará su impacto en la aplicación.
- Si el problema es confirmado, se buscará una solución.
- Se informará sobre el estado y la resolución del problema cuando sea posible.

### Recomendaciones

- No publiques vulnerabilidades sin corregir en Issues públicos.
- No compartas contraseñas, datos personales ni información sensible.
- Evita divulgar detalles que puedan comprometer la seguridad de otros usuarios.

## Security Commitment

MyLife busca mantener un entorno seguro para sus usuarios mediante buenas prácticas de desarrollo, protección de información y corrección de posibles vulnerabilidades.

**Gracias por ayudar a mantener MyLife seguro.** 🐷💗
